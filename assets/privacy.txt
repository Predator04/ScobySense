ScobySense — Privacy Policy
Last updated: 2026-10-28

ScobySense is a community-built Android companion for The Fermenstation
(KOMBU) kombucha brewer. Published at:
https://github.com/Predator04/ScobySense

WHO SEES WHAT
=============
ScobySense never operates its own backend. The app runs entirely on
your device and talks to third-party services on your behalf:

- Amazon Cognito (cognito-idp.us-east-1.amazonaws.com)
    Your email and password are sent only to Amazon Cognito to sign
    you into the same Kombu AWS account the official app uses.
    ScobySense never sees, logs, or forwards those credentials anywhere
    else.

- Kombu AWS AppSync GraphQL (*.appsync-api.us-east-1.amazonaws.com)
    The Cognito ID token from above is sent with each request to read
    device status, brew-cycle history, and alert rules associated with
    your account. All authorization is enforced by AWS, not ScobySense.

- GitHub Releases API (api.github.com/repos/Predator04/ScobySense)
    ScobySense asks GitHub for the latest release to check for app
    updates. No account identifier is sent.

That's it. No analytics SDK, no crash reporter, no ads network, no
telemetry endpoint operated by this project.

WHAT STAYS ON YOUR DEVICE
=========================
- Cognito tokens are stored in Android Keystore via
  flutter_secure_storage and are only used to re-auth against Cognito.
- Temperature history samples are kept in Shared Preferences for
  charting; capped at 2000 points per device.
- Preferences (°C/°F toggle, notification toggle, scheduling drafts)
  are local-only Shared Preferences values.
- Downloaded APKs for in-app updates land in the app's external files
  directory and are overwritten by the next download.

Clearing the app's data (Android Settings → Apps → ScobySense →
Storage → Clear data) removes all of the above.

NOTIFICATIONS
=============
ScobySense can show local Android notifications when a configured
alert rule's temperature threshold is crossed or when a brew timer
completes. These are generated locally while the app is running. The
server-side push system used by the official Kombu app (Firebase Cloud
Messaging) is NOT part of ScobySense.

DATA WE DO NOT COLLECT
======================
- We do not sell any data because we do not collect any.
- We do not run an analytics or crash service.
- We do not share your Cognito credentials, AWS data, or device
  telemetry with any third party. Those stay between your device, AWS,
  and GitHub (for update checks only).

DEVICE CONTROL
==============
ScobySense's write-control path (toggling heaters, sending brew
timers) is gated behind an explicit "Show controls" expander and a
confirmation dialog. The command payload wrapper has not yet been
confirmed against the real device — see command_service.dart
(PAYLOAD_WRAPPER_TODO). We do not auto-send any device command.
